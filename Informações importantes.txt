Esse documento vai apresentar os principais pontos do projeto e suas respectivas fases.




início: Definindo as operações.


def soma(a, b):
    return a + b

def subtracao(a, b):
    return a - b

def multiplicacao(a, b):
    return a * b

def divisao(a, b):
    if b == 0:
        return "Erro: divisão por zero!"
    return a / b


Usamos def para definir as operações (soma, subtração, multiplicação, divisão) e como cada uma vai funcionar:
obs: adicionamos também uma operação para caso seja feita uma divisão por 0, o app retorne como erro.

Decisão das funções:

if op == "+":
    print("Resultado:", soma(x, y))
elif op == "-":
    print("Resultado:", subtracao(x, y))
elif op == "*":
    print("Resultado:", multiplicacao(x, y))
elif op == "/":
    print("Resultado:", divisao(x, y))
else:
    print("Operação inválida")


Esse bloco **decide qual função chamar** com base na operação escolhida:
  - Se o usuário digitou `"+"`, chama a função `soma(x, y)`.
  - Se digitou `"-"`, chama `subtracao(x, y)`.
  - Se digitou `"*"`, chama `multiplicacao(x, y)`.
  - Se digitou `"/"`, chama `divisao(x, y)`.
  - Caso o usuário digite algo diferente, mostra `"Operação inválida"`.
