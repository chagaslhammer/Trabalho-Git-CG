Esse documento vai apresentar os principais pontos do projeto e suas respectivas fases.




início: Definindo as operações.


def soma(a, b):
    return a + b

def subtracao(a, b):
    return a - b

def multiplicacao(a, b):
    return a * b

def divisao(a, b):
    if b == 0:
        return "Erro: divisão por zero!"
    return a / b


Usamos def para definir as operações (soma, subtração, multiplicação, divisão) e como cada uma vai funcionar:
obs: adicionamos também uma operação para caso seja feita uma divisão por 0, o app retorne como erro.

try:
    num1 = float(input("Digite o primeiro número: "))
    num2 = float(input("Digite o segundo número: "))
except ValueError:
    print("Erro: você precisa digitar números válidos.")

Aqui adicionamos a entrada dos números que serão utilizados nas operações e uma validação para impedir que sejam inseridos valores inválidos.

if opcao == "1":
